# Guide d'utilisation — Boomer ConX

## Pour bien commencer avec votre nouveau téléphone

---

## Étape 1 : Ouvrir l'application

1. Cherchez l'icône **Boomer ConX** sur votre écran d'accueil
2. Appuyez dessus une fois pour l'ouvrir

---

## Étape 2 : Choisir votre langue

1. L'application vous demande de choisir votre langue
2. Appuyez sur **Français** (le gros bouton bleu)
3. Appuyez sur **Suivant**

---

## Étape 3 : Créer votre NIP

Le NIP est un code secret à 6 chiffres. C'est comme le code de votre carte de débit.

1. Choisissez 6 chiffres que vous allez retenir (par exemple : votre date de naissance inversée)
2. Tapez vos 6 chiffres dans la première case
3. Retapez les mêmes 6 chiffres dans la deuxième case
4. Appuyez sur **Confirmer**

**Important :** Écrivez votre NIP sur un papier et gardez-le dans un endroit sûr chez vous (pas dans votre portefeuille).

---

## Étape 4 : L'écran d'accueil

Vous voyez maintenant 6 gros boutons. Voici ce que chacun fait :

| Bouton | Ce qu'il fait |
|--------|---------------|
| **Sauvegarde** | Copie vos contacts et photos pour ne pas les perdre |
| **Coffre-fort** | Garde vos mots de passe en sécurité |
| **Urgence (ICE)** | Affiche vos contacts d'urgence même si le téléphone est verrouillé |
| **Protection arnaque** | Vous avertit quand un message texte ou un appel est une arnaque |
| **Accessibilité** | Rend le texte plus gros et plus facile à lire |
| **Lanceur** | Simplifie votre écran d'accueil |

---

## Comment sauvegarder vos contacts

C'est la chose la plus importante à faire en premier!

1. Sur l'écran d'accueil, appuyez sur **Sauvegarde**
2. Appuyez sur le gros bouton **Contacts**
3. Le téléphone va vous demander la permission de lire vos contacts → Appuyez sur **Autoriser**
4. Attendez que le message **« Sauvegarde terminée! »** apparaisse
5. C'est fait! Vos contacts sont en sécurité

**Pour restaurer vos contacts sur un nouveau téléphone :**
1. Installez Boomer ConX sur le nouveau téléphone
2. Connectez-vous avec le même courriel
3. Allez dans **Sauvegarde** → **Restaurer**

---

## Comment enregistrer un mot de passe

1. Sur l'écran d'accueil, appuyez sur **Coffre-fort**
2. Appuyez sur le bouton **+** (en bas à droite)
3. Remplissez :
   - **Nom du site** : par exemple « Desjardins » ou « Vidéotron »
   - **Nom d'utilisateur** : votre courriel ou nom d'utilisateur
   - **Mot de passe** : votre mot de passe pour ce site
4. Choisissez une **catégorie** : Banque, Courriel, Réseaux sociaux ou Autre
5. Appuyez sur **Enregistrer**

**Pour voir un mot de passe enregistré :**
1. Ouvrez le **Coffre-fort**
2. Trouvez le site dans la liste
3. Appuyez sur l'icône de l'œil 👁 pour voir le mot de passe
4. Appuyez encore pour le cacher

---

## Comment ajouter un contact d'urgence

1. Sur l'écran d'accueil, appuyez sur **Urgence (ICE)**
2. Appuyez sur le bouton **+** (en bas à droite)
3. Entrez :
   - **Nom** : par exemple « Jean-Pierre » (votre fils)
   - **Numéro de téléphone** : son numéro
   - **Lien de parenté** : par exemple « Fils »
4. Vous pouvez aussi ajouter :
   - Votre **groupe sanguin**
   - Vos **allergies**
   - Vos **médicaments**
   - Votre numéro de **carte RAMQ**

**Pourquoi c'est important :** Si quelque chose vous arrive, les ambulanciers pourront voir ces informations même si votre téléphone est verrouillé.

---

## La protection contre les arnaques

L'application surveille automatiquement vos messages texte et vos appels.

**Si vous recevez un message suspect :**
- Un gros avertissement rouge va apparaître
- Il va vous dire POURQUOI c'est une arnaque
- Vous pouvez appuyer sur **Bloquer** pour bloquer le numéro
- Vous pouvez appuyer sur **Signaler** pour aider les autres

**Exemples de messages frauduleux courants :**
- « Vous avez gagné un prix! » → **C'est une arnaque**
- « Revenu Québec : vous avez un remboursement » → **C'est une arnaque** (le vrai Revenu Québec n'envoie pas de textos)
- « Votre compte Desjardins est bloqué » → **C'est une arnaque** (appelez Desjardins directement au 1-800-224-7737)
- « Postes Canada : payez les frais de livraison » → **C'est une arnaque**

**Règle d'or :** Ne cliquez JAMAIS sur un lien dans un message texte. Si vous avez un doute, appelez directement l'entreprise avec le numéro sur leur site web ou sur votre carte.

## Comment agrandir le texte

Si le texte est trop petit :

1. Sur l'écran d'accueil, appuyez sur **Accessibilité**
2. Sous **Taille du texte**, glissez le curseur vers la droite pour agrandir
3. Vous voyez un aperçu du texte qui change en temps réel
4. Les tailles disponibles : Petit → Normal → Grand → Très grand → Maximum

**Contraste élevé :** Si vous avez de la difficulté à distinguer les couleurs, activez le bouton **Contraste élevé**. Le texte deviendra plus foncé et plus facile à lire.

---

## Reconnecter votre WiFi

Quand vous changez de téléphone, vous devez reconnecter votre WiFi.

1. Allez dans **Sauvegarde** → **Réseaux WiFi**
2. L'application vous montre la liste des réseaux que vous utilisiez
3. Appuyez sur le réseau de votre maison
4. L'application vous guide étape par étape pour le reconnecter
5. Si vous aviez enregistré le mot de passe WiFi, appuyez sur **Copier** puis collez-le dans les paramètres

**Où trouver votre mot de passe WiFi :** C'est souvent écrit sur une étiquette collée sous ou derrière votre routeur (la petite boîte avec des lumières qui clignote).

---

## Reconnecter vos appareils Bluetooth

Pour reconnecter vos écouteurs, haut-parleurs ou montre :

1. Allez dans **Sauvegarde** → **Appareils Bluetooth**
2. L'application vous montre les appareils que vous utilisiez avant
3. Appuyez sur l'appareil que vous voulez reconnecter
4. Suivez les instructions qui s'affichent (chaque appareil est différent)

**Truc général :** Pour la plupart des écouteurs Bluetooth, il faut maintenir le bouton d'alimentation enfoncé pendant 3 à 5 secondes jusqu'à ce qu'une lumière clignote.

---

## Réinstaller vos applications

1. Allez dans **Sauvegarde** → **Mes applications**
2. Vous voyez la liste de toutes vos anciennes applications
3. Appuyez sur une application pour l'installer depuis le Play Store
4. Appuyez sur **Installer** dans le Play Store
5. Répétez pour chaque application que vous voulez garder

---

## En cas de problème

| Problème | Solution |
|----------|----------|
| J'ai oublié mon NIP | Désinstallez et réinstallez l'application. Vos sauvegardes dans le nuage sont toujours là. |
| Le texte est trop petit | Allez dans **Accessibilité** et agrandissez le texte |
| Je ne retrouve pas mes contacts | Allez dans **Sauvegarde** → **Contacts** → **Restaurer** |
| L'application ne s'ouvre pas | Redémarrez votre téléphone (maintenez le bouton d'alimentation 10 secondes) |
| Un message dit « Autoriser » | Appuyez sur **Autoriser** — c'est normal, l'application a besoin de ces permissions pour fonctionner |

**Si rien ne fonctionne :** Appelez votre enfant ou petit-enfant! 😊
